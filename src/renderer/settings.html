Frame-time source (graph, 1% low and pacing)
Game: time between the frames the game submits, which is what a frame cap flattens. Display: when each frame reached the screen; under v-sync this snaps to refresh steps and looks jumpier even when delivery is smooth. Driver frame generation (AFMF) always uses display timing.

FPS counts frames that actually reached the display, so frame generation is counted correctly. 1% low is the 99th-percentile frame time over its window, using the frame-time source above.

Upscaler detection

SuperLay reads the libraries the game has loaded (DLSS, FSR 2/3/4, XeSS, OptiScaler) and their versions. Anti-cheat protected games block that, so SuperLay checks which of the game's own DLLs are mapped in memory instead. A filled dot means active; a hollow dot means shipped with the game but not confirmed. DLSS presets and AMD's driver-side FSR 4 upgrade aren't exposed to other apps, so they're labelled as capabilities, not facts.

    Limiter mode

    SuperLay sets caps through RTSS's own profile API, the same one MSI Afterburner uses; RTSS does the in-game limiting. RTSS keeps its profiles under Program Files, so the first cap each session asks for administrator permission once (never, if SuperLay runs as admin); a small helper then stays running until SuperLay closes, and it can only change RTSS frame caps. Changes take effect immediately, even mid-game. Turn on Pacing in Metrics to see how steady frames are under the cap.

    OptiScaler

    OptiScaler swaps the upscaler a game uses. It intercepts the game's DLSS, FSR or XeSS and runs the one you pick instead, for example FSR 4 on a Radeon in a game that only offers DLSS or XeSS. In game, press Insert to open its menu and choose the upscaler.

    SuperLay installs the official release and removes it exactly, restoring any game files it replaced. SuperLay isn't affiliated with the OptiScaler team; report installer problems to SuperLay, not to them.

    Single-player only. Mods like OptiScaler can get accounts banned in online games. SuperLay blocks games where it finds anti-cheat.
    Using RTSS? OptiScaler recommends turning on Use Microsoft Detours API hooking in RTSS → Setup, and turning RTSS off when using OptiScaler's own frame generation (OptiFG).
